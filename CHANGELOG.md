# Changelog

## Unreleased

- Added a portable single-file Windows desktop app (`MarkItDown-Web.exe`) that runs in its own window with no server, no port, and no network access; built with `build_exe.bat` and smoke-tested in GitHub Actions.

## 1.0.0 — 2026-07-31

- Added drag-and-drop local file conversion.
- Added side-by-side Markdown source editor and sanitized rendered preview.
- Added edited Markdown copy and download actions.
- Added automatic private runtime bootstrap for Windows, macOS, and Linux.
- Added upload size, file-extension, filename, and browser security controls.
